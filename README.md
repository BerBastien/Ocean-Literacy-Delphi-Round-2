# Delphi Round 2: Thematic Grouping Networks

An R analysis of 27 responses to an exercise grouping topics related to oceans, biodiversity, and climate. It generates connections between topics assigned to the same group by each participant, network visualizations, threshold curves, and hierarchical clusters. A Shiny application is included for exploring the networks.

## Public Data and Privacy

The public data have been anonymized using neutral IDs, `Expert_001`–`Expert_027`, that remain consistent across files. Direct identifiers, personal attributes, and open-ended comments have been removed. Response patterns and proposed group titles are retained.

## Requirements and Execution

Tested with R 4.5.3. Direct dependencies are readxl, dplyr, tidyr, stringr, igraph, ggraph, ggplot2, fs, inflection, writexl, and shiny. `renv.lock` records their versions and transitive dependencies. Installation requires access to CRAN; some platforms may also require compilation tools.

From the repository root, restore the environment:

```r
install.packages("renv", repos = "https://cloud.r-project.org")
renv::restore(project = ".", prompt = FALSE)
```

Because the repository does not activate renv automatically, explicitly load its environment when running the analysis, validation, or application:

```sh
Rscript -e 'renv::load(project="."); source("run_analysis.R")'
Rscript -e 'renv::load(project="."); source("scripts/validate.R")'
Rscript -e 'renv::load(project="."); shiny::runApp("app")'
```

Alternatively, without an isolated environment, run `Rscript scripts/install_dependencies.R`, followed by `Rscript run_analysis.R`. This installs the available package versions, which may differ from those pinned in the lockfile.

The pipeline overwrites only derived outputs in the public copy. Each script in `src/` can also be run individually, in the order shown, from the repository root. Neither the analysis nor the local application requires private files, credentials, or remote services.

## Scientific Scope and Historical Results

The analysis preserves pair generation within each expert's groups, exclusion of “Indeciso” (undecided) and “Tema Independiente” (independent topic), undirected networks, spectral layouts (`eigen`) for aggregate networks, and hierarchical clustering using Euclidean distance and average linkage. Individual layouts use Fruchterman–Reingold (`fr`) with a fixed seed.

The 4,668 regenerated valid connections match the reference data. The final cluster memberships match the historical results, although cluster numbers change because of the ordering of the IDs. These numbers should not be interpreted as ranks or substantive categories.

The `MM_*` figures and `legacy_edges.csv` table are retained as historical material: the original active scripts do not contain a complete procedure for regenerating them. They are not inputs to the main pipeline. The reference figures retain their original visual limitations. See `docs/CHANGES.md`.
